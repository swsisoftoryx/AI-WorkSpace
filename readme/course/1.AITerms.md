## LLM

- They guesses the most likely next piece of a work(a token) based on massive patterns they learned from reading basically the entire internet.


## Gen AI/ Generative AI
- This can just give you information.
- Can not execute task on your behalf.
- It's a prediction Machine.
- **LImitations**
- Can't execute

## AI agent
- Gen AI/ Generative AI + Action
- Brain - LLM models
- Tools - All the tools available to do actions (Send email, web search, call, calculator etc)
- Memory - Agent can memorize what task it got, all the details
- Loop - Agent work in a loop, it works until it finish the work

## Agentic AI
- It is a system of Agent.
- It will coordinate with Multiple Ai agents to execute tasks.
- It will divide the huge task into smaller tasks and each AI agent will start working on with coordinated way.
- First It will plan -> divide task into smaller task -> Assign to expert AI agents

## Chatbots
- Chatbots are reactive - you ask a question, it answers.
## AI ahgents
- AI agents are proactive. YOu give them a high level goal, like research the delevery fees of Blinkit and Zepto and email me a comparison table and they figure out the steps to get it done autonomously.
## The Core Agent Loop
- Every agent runs a continuous loop:
- Preceive(look at the environment)
- THink (Figure out the best move)
- Act (Use a tool to do it)
- Observe (Check the result)
- It repeats this cycle until the task is fully completed
## The ReAct Pattern
- ReAct stands for Reasoning + Acting
- Before taking any action, the agent explicitly writes down it's thought process.
- It's like forcing the AI to think out loud
- This prevents random, impulsive mistakes.
## Tools : The AI's super power
- On it's own, an LLM is like a genius locked in a room without internet, it wonly knows it's past training data.
- Tols give it access to the real world - allowing it to call API's, search the web, run python code or check live IPL scores.
## Memory : Curing AI Amnesia
- By default, LLMs have no memory of pas chats. Every conversation start blank
- To fix this, agents use external database to store working memory for the current task and episodic memory to remember how they specific bug for you last week.
## RAG : Your private AI brain
- Retrieval Augmented Generation : Lets you give AI access to your private data without retraining the model
- If you ask What is our diwali bonus policy ?
- It searches your internal HR docs, grabs jthe relevant paragraph, and feed it to the LLM to answer accurately
## Vector Databases
- To make RAG work, we convert text into vectors - long lists of numbers acting as mathmatical fingerprint
- A bvector database searches based on meaning, not exact words
- In this mathmatical space, Xomato and Swiggy are stored close far away from IRCTC
## MCP - model context protocol
- COnnecting AI to different apps used to require messy custom code for every single tool
- MCP act like a universal USB port for AI
- YOu build one standard connection, your AI can seamlessly oos
## Smart Agent architecture
- Different problems need different setups
- Chain-of-Thought Forces step by step logic
- Plan and execute creates an upfront plan for predictable tasks
- Reflecion lets the agent check its own work, realize it messed up, and try again until it gets it right.
## Multi Agent System
- Complex jobs need a team
- You can set up a system where a manager agent delegates tasks to specilized worker agent.
It is exactly like a bollywood film crew = have a director planning, a writer scripting, and an editor polishing, all working in parlallel.
## Saftey and Guardrails
- Giving AI tools is risky; a hidden prompt could make it delete files.
- YOu must build Guardrails like Sandboxing to run code safely, or a Human-in-the-loop system that pauses and asks for your final approval before executing a UPI payment
## Cost Management
- Running Com[lex AI gets expensive fast
- Use the 60-30-10 rules: route 60% of simple tasks to fast, cheap models, 30% to mid tier and reserve the top 10% most powerful models
## How to Master Agentic AI
- YOu can not learn just by watching Videos or taking notes
- Start small with a simple chatbot, ad a tool like web search, then slowly add memory and RAG
