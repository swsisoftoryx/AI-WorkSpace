## AI fundamentals
- **AI prompts**
    - ROLE: eg. Act like a professional Frontend engineer in react
    - Context: Give it all the background information.
    - Command: Tell it what you want it to do.
    - Format: Define the format
    - The quality of your Output will never exceed the quality of the input.
- **Pick a Tool and dont switch**. Be the master in one tool.(1. Claude, 2. ChatGPT, 3. Gemini)
- **Pull Vs Push** Prompting (Pull means - AI will ask relevent questions before making any change)
- Push -> you will provide info and it will do as per AI. 
- Master prompts for every role in your life.
- **How to Prompt**
```
Role: Tell it who to be like.
COntext: Give it all the background information.
Command: Tell it what you want it to do.
Format: Tell it how you want the output
```
- **master Prompt**
- Create this and save it somewhere. Provide this to AI before starting anything
```
I want to create a master prompt for my role as Senior Software developer and ask me all the questions you need to create it for me
- Use the above command and refine it and save the final output in pdf format
```
- This will give AI context, who you are.
- **System Prompt**
```
You are an expert AI engineer. I want you to create a system prompt that writes emails. Ask me all the questions you need to create it.
- Answer the questions
- Then refine it.
Copy systme prompt into custom GPT
```
